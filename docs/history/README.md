audit snapshots kept for provenance. They are **not** current reference material
and may describe features, plans, or states that have since changed.

`STATUS.md`, `ROADMAP.md`; and under `docs/`: `QUICKSTART.md`, `USAGE_EXAMPLES.md`,
`TESTING.md`, `CONTRIBUTING.md`, plus `docs/reference/` for the wired Phase-4
module guides (CVE, threat-intel, UEFI integrity).
